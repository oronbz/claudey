Before reading or publishing issues, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels.
Before triaging, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout.
Before exploring or changing the project, read `docs/agents/domain.md`.
